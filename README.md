# Incremental Clicker — Starter

Simple incremental/clicker game starter. This repo is designed to teach core concepts and publish to GitHub Pages.

## Quick start (developer)

1. Clone: `git clone https://github.com/kchends/test-webpage.git`
2. Create a branch: `git checkout -b my-feature`
3. Edit files (index.html, style.css, game.js)
4. Run locally: `python -m http.server 8000` or `npx http-server` and open `http://localhost:8000`
5. Commit & push: `git add -A && git commit -m "feat: ..." && git push --set-upstream origin my-feature`
6. Open a Pull Request on GitHub and request review.

## Project structure
- `index.html` — main page
- `style.css` — styles
- `game.js` — game logic

## Deployment
This repo is hosted on GitHub Pages: https://kchends.github.io/test-webpage/
Push to `main` or `gh-pages` depending on your workflow.
